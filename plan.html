Kế hoạch nâng ccswitch từ công cụ đổi tài khoản Claude Code trên Windows thành nền tảng quản lý & chạy song song nhiều tài khoản, nhiều nhà cung cấp AI — có dashboard 3D theo dõi trực quan.

Mục tiêu

Sáu đích đến

Điều thú vị: cả sáu chỉ là những cách ghép lại của một nguyên lý cốt lõi bên dưới.

1 · Đa nhà cung cấp

Claude, Codex (GPT), Gemini, Cursor… mỗi cái một adapter.

2 · Nhiều phiên / 1 tài khoản

Clone credential ra N config dir để chạy agent song song.

3 · Nhiều tài khoản song song

Mỗi phiên một danh tính, điều phối & theo dõi tập trung.

4 · Đa nền tảng

Một binary Go cho Windows + Linux (bỏ macOS).

5 · Ghép được thành flow

Primitive nhỏ → người dùng tự dựng luồng theo ý mình.

6 · Giao diện 3D

Dashboard "phòng điều khiển đội agent", theo dõi realtime.

Xương sống

Nguyên lý cốt lõi

Trỏ một CLI vào một thư mục config biệt lập qua một biến môi trường, và biết file nào là token/danh tính (riêng) — file nào là thói quen máy (chung).

Claude: biến CLAUDE_CONFIG_DIR · riêng .credentials.json + .claude.json · chung nối link + 19 khoá whitelist. Mọi mục tiêu chỉ là tổ hợp lại primitive này.

Cách ghép

Primitive → Adapter → Flow

Verb là API, flow là công thức. Ba tầng để người dùng tự dựng luồng — đúng yêu cầu "build thành nhiều flow theo ý người dùng".

Verb nguyên thuỷ

create · run · clone · link · sync · fleet · remove — nhỏ & trực giao.

→

Adapter provider

Mỗi AI khai báo biến env, file riêng/chung, và verify "đã đo".

→

Flow người dùng

CLI script / flows.toml / adapter plugin — tự đặt tên luồng.

Nhà cung cấp

Mỗi AI, một linh vật

Thứ tự thêm adapter. Mỗi provider có mascot riêng trong dashboard (màu thương hiệu + dấu nhận diện).

Mỗi pha ra được một bản dùng thật, và chỉ đóng khi đạt hết Định nghĩa Hoàn thành (DoD). Chi tiết đầy đủ ở docs/PLAN.md.

Pha 0 · Đo giả định bắt đầu ở đây
"Đã đo — không suy luận": biết primitive có đứng vững trước khi viết Go.
  • Đo token Linux nằm ở file hay keyring (rủi ro #1)
  • Đo cơ chế CODEX_HOME / Gemini / Cursor
  • Đo tạo junction (Win) & symlink (Linux) từ Go, không cần admin
Mọi ô có kết luận đo được; mỗi provider gắn nhãn stable/experimental/unsupported.
Pha 1 · Lõi Go + adapter Claude kế tiếp
Thay thế trọn vẹn tk v1, chạy Windows+Linux, bỏ Python.
  • Khung Go + CI 2 OS · trừu tượng link (junction/symlink)
  • jsonutil: khoá JSON trùng hoa/thường + ghi nguyên tử
  • Adapter interface + Claude (whitelist 19 khoá)
  • Verb: create · run · list · sync · remove (xoá an toàn)
Cả 2 OS: tạo/đổi tài khoản không đăng nhập lại; remove không đụng dữ liệu gốc; hết phụ thuộc Python.
Pha 2 · Chạy song song mục tiêu 2·3
Nhiều phiên / 1 tài khoản và nhiều tài khoản song song.
  • clone --into N: N config dir riêng, né đua ghi .claude.json
  • fleet + registry PID + status
  • Cảnh báo hạn mức "tiêu gấp N"
4 phiên/1 account + 3 account song song chạy ổn; test 10 phiên đồng thời JSON vẫn hợp lệ.
Pha 3 · Flow ghép được mục tiêu 5
Người dùng tự dựng luồng, ba tầng.
  • flows.toml (khai báo) + adapter plugin TOML
  • 3 flow mẫu: fanout · squad · agents
Viết flow mới không cần sửa mã Go; thêm provider giả bằng plugin TOML.
Pha 3b · UI Dashboard 3D mục tiêu 6
tk dash: web cục bộ (Go embed) đọc dữ liệu sống của fleet.
  • Server localhost + WebSocket; front React Three Fiber
  • Mascot 3D biết đi/biểu diễn hoạt động · orb theo trạng thái
  • Responsive điện thoại + fallback 2D
Phản ánh đúng fleet đang chạy; mượt trên điện thoại; tắt UI không ảnh hưởng lõi.
Pha 4–6 · Codex → Gemini → Cursor mục tiêu 1
Mỗi provider lặp cùng quy trình dựa trên số liệu Pha 0.
  • Viết adapter + verify "tách thật" trên 2 OS
  • Identity/token đúng định dạng + mascot thương hiệu
create/run/list/remove/verify đúng; đổi qua lại không lẫn token; trạng thái gắn nhãn trung thực.

Giao diện

Phòng điều khiển đội agent

Web dashboard cục bộ do chính binary Go phục vụ (Go embed — vẫn một file). 3D bằng React Three Fiber, fallback 2D.

Trực quan hoá

Mỗi provider một cụm có linh vật; mỗi phiên một orb — màu theo trạng thái (chạy / gần cạn / hết hạn mức / nghỉ).

Quy tắc render thật

InstancedMesh (đội orb = 1 draw call), FogExp2 (chiều sâu), ACES + antialias lúc khởi tạo. Tôn trọng prefers-reduced-motion.

Hệ màu & typography sinh từ skill ui-ux-pro-max (Modern Dark, Inter) — lưu ở design-system/ccswitch-dashboard/MASTER.md.

Sòng phẳng

Rủi ro đã ghi rõ

Hạn mức khi song song: N phiên trên một tài khoản tiêu hạn mức gấp N — công cụ cảnh báo, không giấu.
Điều khoản dịch vụ: dùng nhiều tài khoản để vượt hạn mức có thể đi ngược ToS nhà cung cấp; cái mất là tài khoản. Bạn tự cân.
Cơ chế provider đổi nhanh: vì vậy mỗi adapter tách rời + có verify chạy được — đo lại rẻ hơn đoán sai.
Giữ nguyên linh hồn v1: whitelist không blacklist · "đã đo — không suy luận" · xoá an toàn · ghi nguyên tử.
