Bắt đầu từ đâu — đọc 30 giây
1. Bạn có ba cách giao việc, khác nhau về TIỀN (cả ba nằm trên thanh công cụ ngay trên đầu trang):
Bật hạm đội Bật N phiên agent song song trên MỘT tài khoản. Tiêu hạn mức thuê bao. Dùng khi muốn nhiều agent cùng cày một việc.
Chạy workflow Chạy một quy trình nhiều bước, mỗi bước một tài khoản khác nhau. Đây là cách dùng chính: một agent chia việc, vài agent làm, một agent soi.
Hỏi thẳng AI API Gọi thẳng model qua API key. Tiêu tiền theo token, không đụng hạn mức thuê bao. Hợp với việc ngắn.
2. Mỗi agent chạy trong git worktree riêng — nhánh sagent/<tài khoản>-1. Chúng không đụng thư mục làm việc chính của bạn. Xong việc thì xem git log main..sagent/<tài khoản>-1 rồi tự quyết có trộn hay không.

3. Muốn xem ai đang làm gì — khối Tiến độ lượt chạy bên phải nói workflow đang tới bước nào và gãy ở đâu. Mở tab 3D để nhìn từng robot làm việc, tab Workflow để sửa quy trình bằng cách kéo thả.

Cột "chưa đăng nhập" của antigravity là ĐÚNG và không sửa được: nó giữ token trong Windows Credential Manager nên không đọc ra danh tính. Nó vẫn chạy bình thường.
